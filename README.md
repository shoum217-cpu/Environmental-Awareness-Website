# Environmental Awareness Website

## Overview

The Environmental Awareness Website is a simple multi-page website developed using HTML and CSS. The purpose of this project is to educate users about environmental conservation, pollution prevention, and sustainable living practices.

This project was created as part of a web development learning exercise and demonstrates the use of basic HTML, CSS styling, images, hyperlinks, lists, and forms.

---

## Features

### Home Page

* Introduction to environmental awareness.
* Attractive nature-themed images.
* Information about major environmental problems.
* Suggestions on how individuals can help protect the environment.

### About Page

* Information about the environment and its importance.
* Discussion of environmental challenges such as pollution, deforestation, and global warming.
* Benefits of environmental awareness.
* Interesting environmental facts.

### Contact Page

* Contact information.
* Email and phone number fields.
* Feedback form for visitors.
* Message submission section.
