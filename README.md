# 🌍 Environmental Awareness Website

## Overview

The **Environmental Awareness Website** is a multi-page website developed using **HTML5** and **CSS3**. The primary goal of this project is to spread awareness about environmental conservation, pollution prevention, wildlife protection, and sustainable living practices.

The website provides users with information about major environmental issues and encourages individuals to take small but meaningful steps toward protecting our planet.

This project was created as part of a web development learning exercise and demonstrates the use of fundamental web development concepts such as page navigation, hyperlinks, images, forms, lists, and CSS styling.

## Live Website

🔗 Website: https://creative-dusk-4fe49d.netlify.app/

## Features

### 🏠 Home Page

* Introduction to environmental awareness.
* Nature-themed images showcasing the beauty of the environment.
* Information about major environmental problems.
* Practical suggestions on how individuals can contribute to environmental conservation.
* Clean and visually appealing design.

### 📖 About Page

* Detailed information about environmental awareness and its importance.
* Explanation of major environmental issues such as:

  * Air Pollution
  * Water Pollution
  * Deforestation
  * Global Warming
  * Wildlife Conservation
* Interactive hyperlinks that allow users to learn more about specific environmental topics from external resources.
* Interesting facts about nature and the environment.

### 📞 Contact Page

* Contact information section.
* Visitor feedback form.
* Input fields for name, email, and contact details.
* Message submission area for suggestions and feedback.

## How to Run the Project

1. Download or clone the project files.
2. Ensure all HTML files, CSS files, and images are stored in the same folder.
3. Open `index.html` using any modern web browser.
4. Navigate through the website using the Home, About, and Contact links.
